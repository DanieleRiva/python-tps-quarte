### Assegnazione composta

Ogni operatore aritmetico ha la sua forma di assegnazione:

```python
punteggio = 10
punteggio += 5     # equivale a: punteggio = punteggio + 5
punteggio *= 2
punteggio //= 3
```

```python
voto = 7
print(voto >= 6)         # True
print(voto == 10)        # False
print("a" < "b")         # True: confronto lessicografico
```

Python permette **confronti concatenati**, molto leggibili:

```python
eta = 17
if 14 <= eta < 18:
    print("Adolescente")
```

## Operatori logici: `and`, `or`, `not`

Combinano espressioni booleane.

```python
piove = True
vento = False

if piove and not vento:
    print("Prendi l'ombrello.")

if piove or vento:
    print("Copriti bene.")
```

<Aside type="tip" title="Short-circuit">
Python valuta gli operatori logici con **cortocircuito**: in `a and b`, se `a` è falso non valuta `b`; in `a or b`, se `a` è vero non valuta `b`. Si sfrutta per evitare errori:

```python
testo = None
if testo and len(testo) > 0:    # len(None) darebbe errore
    print("non vuoto")
```
</Aside>

## Operatori di appartenenza: `in`, `not in`

Verificano se un valore è presente in una collezione o in una stringa.

```python
vocali = "aeiou"
if "e" in vocali:
    print("Sì, e è una vocale.")

numeri_primi = [2, 3, 5, 7, 11]
print(9 not in numeri_primi)      # True
```

Funzionano anche sui dizionari (cercano tra le **chiavi**):

```python
studente = {"nome": "Luca", "eta": 17}
print("nome" in studente)         # True
print("Luca" in studente)         # False - non è una chiave
```

## Operatori di identità: `is`, `is not`

`is` controlla se due nomi fanno riferimento allo **stesso oggetto** in memoria, non se hanno lo stesso valore.

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)        # True: stesso valore
print(a is b)        # False: sono due oggetti diversi
print(a is c)        # True: c è un alias di a
```

L'uso tipico è il confronto con `None`:

```python
valore = None
if valore is None:   # mai `valore == None`
    print("vuoto")
```

## Precedenza degli operatori (schema essenziale)

Dall'**alto** (precedenza maggiore) al **basso**:

1. `**`
2. `+x`, `-x`, `~x` (unari)
3. `*`, `/`, `//`, `%`
4. `+`, `-`
5. confronti `<`, `<=`, `>`, `>=`, `==`, `!=`
6. `not`
7. `and`
8. `or`

In caso di dubbio, **usa le parentesi**: rendono l'espressione più chiara e sicura.

```python
# Scrivere così è chiaro, anche se non necessario:
if (eta >= 14) and (eta < 18):
    ...
```

## Esempio completo · controllo credenziali

```python
utente = input("Utente: ").strip()
password = input("Password: ")

utenti_validi = ["admin", "giulia", "luca"]

if utente in utenti_validi and len(password) >= 8:
    print(f"Benvenuto, {utente}.")
elif utente not in utenti_validi:
    print("Utente sconosciuto.")
else:
    print("Password troppo corta.")
```

- Verifica che `0 and print("eseguita?")` **non** stampa nulla per via del cortocircuito.
