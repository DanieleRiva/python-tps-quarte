## Perché Python

Python è un linguaggio **interpretato**, **tipizzato dinamicamente** e **multiparadigma**. Dal 1991 è diventato lo standard per didattica, automazione, data science, web, scripting e molto altro.

- **Sintassi leggibile**: l'indentazione è parte del linguaggio e forza uno stile pulito.
- **Pronto all'uso**: la libreria standard copre file, rete, date, matematica, test, basi di dati.
- **Ecosistema enorme**: con `pip` si installano in un comando pacchetti per quasi qualsiasi scopo.
- **Portabile**: lo stesso programma gira su Windows, macOS e Linux.

<Aside type="note" title="Versione di riferimento">
In questa guida usiamo **Python 3.11+**. Il codice resta compatibile con qualsiasi 3.10+ se non diversamente indicato.
</Aside>

## Installazione rapida

### Windows

1. Vai su [python.org/downloads](https://www.python.org/downloads/) e scarica l'ultima versione 3.x.
2. Lancia l'installer e **spunta "Add python.exe to PATH"** prima di premere *Install Now*.
3. Apri PowerShell e verifica:

```powershell
python --version
pip --version
```

### macOS / Linux

Su macOS conviene installare Python con [Homebrew](https://brew.sh/):

```bash
brew install python
```

Sulle principali distribuzioni Linux Python 3 è già presente; se manca `pip`:

```bash
sudo apt install python3 python3-pip   # Debian / Ubuntu
```

## Eseguire uno script

Crea un file `saluto.py` con questo contenuto:

```python
# saluto.py - primo programma
nome = input("Come ti chiami? ")
print(f"Ciao {nome}, benvenuto in Python!")
```

Poi, nel terminale aperto nella cartella del file:

```bash
python saluto.py
```

Per esperimenti rapidi conviene la **REPL interattiva**: lancia `python` senza argomenti, scrivi un'espressione, premi *Invio* e vedi subito il risultato.
